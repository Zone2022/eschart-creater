# 简评文案契约（insights.json 各字段写法）

通用要求：
- 数据分析师口吻：只陈述数据事实 + 阈值判断 + 动作指向；不用修饰词、不用"显著提升"这类无数字结论。
- 所有数字必须与 analysis.json 一致，禁止编造；金额用"万"保留 1 位小数，ROI 保留 2 位，百分比保留 1 位。
- 允许使用模板 HTML 标签：`<b>`、`<span class="na">`。
- scene/keyword/audience/brandzone/product/plan 六个键的值为**数组**，元素为 `{"t": 小标题, "c": 内容}`，每键 3~4 条；每条 1~2 句、文字精简，小标题 2~4 字。
- 以 `plan_matrix` 为计划评价主线。禁止使用偏移指数、偏移标签、偏移调整算法或双因素拆解作为评价依据。
- 关键词、人群源表没有计划 ID/计划名：可以按品牌/竞品/行业策略分类，为相应类型的计划提出调整方向；不得宣称某个词或人群包直接导致某个具体计划的结果。

## 字段说明

| 键 | 对应板块 | 结构要求（每条一个小标题） |
|---|---|---|
| `scene` | 营销场景 | 大盘（花费/成交/ROI 及环比、是否守红线 6）→ 场景分化归因 → 拉新表现 → 新场景状态 |
| `keyword` | 关键词 | 宏观统计（总量/分类占比/各类 ROI，保持原口径）→ 对照计划矩阵中对应策略类型的计划评价 → 给问题计划的调价、匹配、否词方向；不做单计划直接归因 |
| `audience` | 人群 | 宏观统计（三类花费/成交/ROI/新客率，保持原口径）→ 对照计划矩阵中对应策略类型的计划评价 → 给问题计划的圈选、出价、素材方向；拉新类看新客率≥50%∧ROI≥5，竞品拦截按三件套，品牌看 ROI |
| `brandzone` | 品销宝 | 需求侧 → 成交侧 → 主要矛盾+建议 |
| `product` | 商品主体 | 基于 `prod_sku`：费比最高 SKU → 费比周度升降 → 高费比 SKU 的控费/承接动作；不得再写概览 KPI 或主品汇总 |
| `plan` | 计划矩阵 | 对比 w0/w1 象限迁移与点位方向 → 汇总本周四象限计划数与花费 → 点名高花费/高优先级计划及双周 ROI、新客率 → 按象限给调整方向；成交人数为 0 的计划列待观察 |
| `optimize` | 优化清单 | **字符串**（单段 callout）：合计规模与占比 → 处置优先级（先砍明确低效 → 再修结构性低效 → 学习期给足 2 周）→ 特殊说明（如竞品拦截包按三件套不关停） |

## 判定标准与措辞映射（引自 8 月方案）
- 合格线 ROI≥5：<5 进入优化或减投流程；整体红线 ROI≥6；警戒线 ROI 4（跌破必须给明确处置）
- 明星计划（ROI≥5 且新客率≥50%）→ 守住 ROI 后分步加预算
- 效率计划（ROI≥5 且新客率<50%）→ 保留收益，优化人群/素材提升拉新
- 拉新潜力（ROI<5 且新客率≥50%）→ 控价并优化转化承接，观察 2 周
- 待调整（ROI<5 且新客率<50%）→ 降预算或暂停，预算转向明星计划
- 拉新类人群包：新客率 <50% → 调条件或减投；竞品拦截人群：不因短期 ROI<5 直接关停，按三件套观察
