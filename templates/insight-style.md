# 简评文案契约（insights.json 各字段写法）

通用要求：
- 数据分析师口吻：只陈述数据事实、环比变化和阈值判断；不得写主观指导、建议、优化方向、调价/出价/圈选/承接动作。
- 所有数字必须与 analysis.json 一致，禁止编造；金额用"万"保留 1 位小数，ROI 保留 2 位，百分比保留 1 位。
- 允许使用模板 HTML 标签：`<b>`、`<span class="na">`。
- scene/keyword/audience/brandzone/product/plan 六个键的值为**数组**，元素为 `{"t": 小标题, "c": 内容}`，每键 3~4 条；每条 1~2 句、文字精简，小标题 2~4 字。
- 以 `plan_matrix` 为计划评价主线。禁止使用偏移指数、偏移标签、偏移调整算法或双因素拆解作为评价依据。
- 关键词、人群优化清单直接使用本周源报表的计划ID、计划名字：每行对应一个“对象 + 具体计划”组合；不得引入外部映射表或按策略猜测计划归属。

## 字段说明

| 键 | 对应板块 | 结构要求（每条一个小标题） |
|---|---|---|
| `scene` | 营销场景 | 大盘（花费/成交/ROI 及环比）→ 场景间数值差异 → 拉新表现 → 新场景数据状态 |
| `keyword` | 关键词 | 宏观统计（总量/分类占比/各类 ROI）→ 对应计划的 ROI、新客率与象限 → 低 ROI 对象的数量、花费与计划名称；不写方向 |
| `audience` | 人群 | 宏观统计（三类花费/成交/ROI/新客率）→ 对应计划的 ROI、新客率与象限 → 低 ROI 对象的数量、花费与计划名称；不写方向 |
| `brandzone` | 品销宝 | 需求侧 → 成交侧；删除“承接”条目 |
| `product` | 商品主体 | 基于 `prod_sku`：费比最高 SKU、费比周度升降及可计算 SKU 数；不得再写概览 KPI、主品汇总或动作 |
| `plan` | 计划矩阵 | 对比 w0/w1 象限迁移与点位方向 → 引用 `plan_value` 的业务亮点/指标<0数量与数值 → 汇总本周四象限计划数与花费 → 点名高花费计划及双周 ROI、新客率；不写调整方向。亮点和需要调整明细由报告自动渲染，不重复编造 |
| `optimize` | 优化清单 | **字符串**（单段 callout）：仅写入选对象数、合计花费、占比、ROI/新客率等客观统计；不写处置优先级或动作 |

## 判定标准与措辞映射（引自 8 月方案）
- 合格线 ROI≥5；整体红线 ROI≥6；警戒线 ROI 4。结论中仅可说明是否达到阈值及对象数量、花费、环比变化。
- 明星计划（ROI≥5 且新客率≥50%）→ 守住 ROI 后分步加预算
- 效率计划（ROI≥5 且新客率<50%）→ 保留收益，优化人群/素材提升拉新
- 拉新潜力：ROI<5 且新客率≥50%
- 待调整（ROI<5 且新客率<50%）→ 降预算或暂停，预算转向明星计划
- 拉新类人群包：新客率≥50% 且 ROI≥5 为达标；竞品拦截人群：以首单转化率、新客客单价、30 天复购率三件套评估，周报可列新客率/新客成本作为代理指标
