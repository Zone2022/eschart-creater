# Halo 站内推广周报 · 业务规则

## 1. 对比口径
- 周环比：本周（周一~周日）vs 上周，两期均为 7 天，不做日均折算。
- ROI 环比以差值表示；新客率等比率指标环比以百分点（pp）表示。
- 计划矩阵明细表新增的“ROI变化率”“新客率变化率”是交互表专用字段，统一按 `(本周值÷上周值-1)×100%` 计算；上周无可比值时显示“新增/—”。这两列不改变正文简评继续采用 ROI 差值、新客率百分点的口径。
- 计划矩阵的“仅看 ROI、新客率均下降计划”按钮：只保留本周 ROI 与新客率均严格低于上周的计划；筛选状态下，在矩阵点位和计划名旁标注两项相对下降率。计划明细的本周花费数值旁展示花费相对上周的上升/下降箭头与变化率；切换到上周视图时该趋势显示“—”。
- 文件名后缀 = 数据所在周的周一（YYYYMMDD），如 20260803。必须核对文件内部"日期"列与后缀所在周一致（曾发生导错周期）。

## 2. 成交与效率口径
- 成交金额 = 直接成交 + 间接成交，**不含预售**；ROI = 总成交金额 ÷ 花费。
- 成交新客数、成交人数、收藏加购为分场景合计、**未跨场景去重**；新客率 = 成交新客数 ÷ 成交人数。
- 货品全站推广成交**含免费流量**，其 ROI 加 ※ 标注、不与纯付费场景直接对比。
- 品销宝（品牌专区报表）花费不在源表口径内，不计算 ROI；账户 sheet 为日粒度，按周求和。
- 人群维度为跨场景拆分口径，合计大于"人群推广"场景值，不与营销场景表直接加总。
- SKU 推广费比 = 推广花费 ÷ 总成交金额。成交金额为 0 时费比不可计算，显示“—”；该指标不等同于花费÷宝贝 GSV 的全店商品费比。

## 3. 分类规则（token 明细见 classification-tokens.json）
- 关键词：含品牌 token → 品牌词；含竞品品牌 token → 竞品词；词类型="关键词包"或含"智选" → 智能词包；其余 → 行业词。同名跨计划词合并汇总。
- 人群：含"竞争/竞店/竞品"或竞品品牌 → 竞品人群；含"喜欢我的/粉丝/老客/预流失/品专/小红书/领券/深度行为/halo/品牌A/I" → 品牌人群；其余（含智能推荐人群）→ 行业人群。
- 计划：货品全站推广 → 全站推广；超级短视频/超级直播 → 内容场；其余按人群规则归入 品牌/竞品/行业人群。
- 商品主体：按`主体名称`汇总全部 SKU；赠品/会员积分/购物金/满赠礼等主体也保留；仅当本周、上周费比均为 0 或不可计算时，不展示该 SKU。
- 策略基线：关键词竞品词按策略不投（花费为 0 属正常，不作异常）。

## 4. 推广计划波士顿矩阵

以计划为评价中心，直接使用计划报表双周指标：横轴为 ROI，中线=5；纵轴为新客率，中线=50%。本周与上周共用同一坐标尺度，以按钮切换；同一计划切周时点位平滑移动，单周新增/退出计划淡入淡出。每个点必须有鼠标悬停提示，显示计划名称及当周核心指标。不计算、不展示、不引用偏移指数、偏移标签或偏移调整算法。

| 象限 | 条件 | 计划评价 |
|---|---|---|
| 明星计划 | ROI≥5 且新客率≥50% | 收益与拉新双达标 |
| 效率计划 | ROI≥5 且新客率<50% | 收益达标、拉新不足 |
| 拉新潜力 | ROI<5 且新客率≥50% | 拉新达标、收益不足 |
| 待调整 | ROI<5 且新客率<50% | 收益与拉新双不达标 |
| 待观察 | 成交人数=0，无法计算新客率 | 样本不足 |

货品全站推广 ROI 含免费流量，矩阵中必须带 ※，只作参考。关键词与人群行直接读取本周源表的计划 ID、计划名，并与对象同一行展示；不得使用额外映射表、猜测或虚构关联。若本周源表缺少这两列，应停止生成并提示缺失字段。

### 4.1 计划贡献评价指标

对本周有花费、且在 `references/plan-product-map.json` 中存在商品映射的计划，按计划内商品名称识别后计算；不得使用计划名称本身识别 US/CN、猫/狗：

`推广收入 × (毛利要求率 - 边际缓冲) × (新客率 × 新客目标权重 + 1) - 2 × 花费`

- 推广收入 = 计划报表的总成交金额；新客率 = 成交新客数 ÷ 成交人数。
- 毛利要求率固定为 0.5；边际缓冲固定为 0。
- 商品名称识别：含“美国”为 US，否则为 CN；含“猫”优先，否则含“狗”或“犬”为狗。无法识别猫/狗的商品不参与综合权重。
- 新客目标权重：US猫=1.5、US狗=1.8、CN猫=1.8、CN狗=2.0。
- 同一计划内多个映射商品按商品数等额分摊计划级推广收入与花费；逐商品计算后汇总，数学上等价于在计划级公式中使用已识别商品目标权重的算术平均值。不得把完整计划收入重复套给每个商品。
- 报告在计划矩阵下自动输出指标最高的 3 个计划作为“业务亮点”，并列出指标小于 0 的计划作为“需要调整”；两张表均展示商品组合识别、商品数、综合权重、推广收入、新客率和指标值。

## 5. 判定标准与优化清单（引自《Halo 8月拉新与人群圈选方案》，2026-08 起生效）
- **单项合格线：ROI ≥5**（<5 进入优化或减投流程）；**整体红线：ROI ≥6**；**效率警戒线：ROI 4**（跌破必须给出明确处置）。
- **优化清单入选条件**：本周花费 ≥500 元（关键词）/ ≥1,000 元（人群、计划）且本周 ROI<5；按本周花费降序。仅展示上周花费大于 0 的对象，不展示本周新增对象；关键词、人群行直接列出本周源表的实际计划名。
- **优化清单新客率过滤**：人群与计划记录剔除本周新客率 >50% 的对象，新客率恰为 50% 的对象保留；关键词对象级源数据无新客率字段，不应用该过滤。
- **人群包分类评价**：
  - 拉新类包（行业人群）：**新客率 ≥50% 且 ROI≥5** 才保留；
  - 竞品拦截人群：按「首单转化率 + 新客客单价 + 30 天复购率」三件套评估，周报以新客率/新客成本为代理指标，**不单看短期 ROI**；
  - 品牌资产人群：看 ROI 与承接客单价。
- **无效判定**：人群规模 <5 万、CTR 明显低于均值、连续 2 周无转化信号 → 调条件或关停。
- 测试节奏：新包/新计划 2 周学习期 → 按合格线汰换 → 放量。

## 6. 文案风格
- 数据分析师口吻：只陈述数据事实与阈值判断，不给出主观指导、建议、行动、出价、人群、承接或预算方向。
- **结论结构化**：各维度简评用 `{"t": 小标题, "c": 内容}` 数组，3~4 条，每条 1~2 句、文字精简。计划按「象限分布/贡献评价结果/重点计划/象限变化」组织；关键词与人群按「宏观统计/对应计划/低效对象」组织。品销宝不得出现“承接”结论。
- 参考线：合格线 ROI 5、警戒线 ROI 4、整体红线 6。SKU 推广费比不预设标准线，按全部 SKU 的相对分布与周度变化判断。

## 7. 报告结构（输出契约详见 templates/report-contract.json）
核心总览 → 品销宝 → 营销场景 → 推广计划波士顿矩阵 → 关键词 → 人群 → 商品主体 → **优化清单**。
无"结论速览"、"下周动作"或"口径附录"独立板块；大盘结论并入营销场景总结。署名：出品：Halo中国 ｜ 模型：<实际生成模型>。
